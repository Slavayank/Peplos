# Peplos

Peplos — переносимый менеджер баз KeePass для Windows, написанный на Rust. Он позволяет открыть существующую базу или создать новую и работает без установки.

## Скачать и запустить

1. Скачайте `Peplos.exe` из [последнего выпуска](https://github.com/Slavayank/Peplos/releases/latest).
2. Сохраните файл в удобной папке и запустите его на Windows x64.
3. Выберите существующую базу KeePass или создайте новую, задав мастер-пароль.

Программа не подписана цифровым сертификатом, поэтому Windows может показать предупреждение о неизвестном издателе. SHA-256 опубликован рядом с файлом выпуска; проверка в PowerShell: `Get-FileHash .\Peplos.exe -Algorithm SHA256`.

## Возможности

- Чтение и сохранение KDBX 3.1 и 4.0; создание базы KDBX 4.0 с мастер-паролем и Argon2id.
- Открытие существующих баз с паролем, файлом-ключом или их сочетанием.
- Поиск, создание и редактирование записей и папок, значки и корзина.
- `Ctrl+C` — скопировать пароль, `Ctrl+B` — логин, `Ctrl+S` — сохранить базу. Пароль удаляется из буфера через 60 секунд, если его содержимое не изменилось.
- `Ctrl+V` — автоввод логина и пароля в предыдущее окно; пароль не помещается в буфер. В полях ввода сочетание работает как обычная вставка.
- Необязательная синхронизация через explicit FTPS с проверкой сертификата. Пароль FTPS хранится в настройках с защитой Windows DPAPI для текущего пользователя. Для передачи используется системный `curl.exe`.

Настройки и список последних баз хранятся в `%APPDATA%\Peplos`, а не в папке программы. Базы и ключевые файлы в репозиторий добавлять не следует.

## Безопасность и ограничения

Peplos не проходил независимый аудит безопасности. Храните резервные копии баз и проверяйте совместимость с KeePass перед использованием важных данных. Забытый мастер-пароль восстановить невозможно. Автоматическая блокировка, встроенное обновление и автоматическое резервное копирование пока не реализованы. При принудительном завершении программы очистка буфера по таймеру не произойдёт; другие приложения могут прочитать буфер до очистки. Возможности редактирования некоторых функций KeePass ограничены. Одновременное редактирование одной базы несколькими программами не поддерживается. Обычный FTP без TLS не используется.

## Сборка

Нужны Windows x64, Rust через rustup и Microsoft C++ Build Tools с Windows SDK. Версия Rust закреплена в `rust-toolchain.toml`, зависимости — в `Cargo.lock`.

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Результат — `Peplos.exe` и файл SHA-256. Тесты:

```powershell
cargo test --locked --target x86_64-pc-windows-msvc
```

Для подписи кода скрипт поддерживает необязательный параметр `-Sign`; опубликованные выпуски могут оставаться неподписанными. Закреплённые версии облегчают повторение сборки, однако побайтовая воспроизводимость пока не подтверждена.
